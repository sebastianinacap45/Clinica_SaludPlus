 Clinica_SaludPlus

Sistema clínico desarrollado en Python y MongoDB Atlas.

Permite la gestión de:
- doctores
- pacientes
- citas médicas

Incluye:
- CRUD completo
- login seguro
- roles y permisos
- contraseñas cifradas
- backup y restauración
- conexión en la nube con MongoDB Atlas
- cumplimiento básico Ley 19.628

---

# Tecnologías utilizadas

- Python 3
- MongoDB Atlas
- PyMongo
- Bcrypt
- Colorama
